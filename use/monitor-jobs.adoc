= 在稽核頁面上監控磁碟區快取作業
:hardbreaks:
:allow-uri-read: 
:icons: font
:imagesdir: ../media/


[role="lead"]
您可以使用NetApp控制台審核頁面監控所有磁碟區快取作業並確定其進度。

.步驟
. 從NetApp控制台選單中，選擇 *管理* > *稽核*。
. （可選）按時間、服務、操作、代理、資源、使用者或狀態進行過濾。
. 探索所有快取和操作。
