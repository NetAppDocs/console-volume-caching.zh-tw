= 設定卷緩存
:hardbreaks:
:allow-uri-read: 
:icons: font
:imagesdir: ../media/


[role="lead"]
若要使用磁碟區緩存，請執行下列步驟進行設定。

* 審查link:../get-started/cache-prerequisites.html["先決條件"]以確保您的環境已準備就緒。
* 建立控制台代理。
* 創建能夠支援卷宗緩存的系統。




== 在NetApp Console中建立控制台代理

下一步是在NetApp Console中建立控制台代理程式。

在使用磁碟區快取之前建立控制台代理，請參閱NetApp Console文檔，其中對此進行了描述。 https://docs.netapp.com/us-en/bluexp-setup-admin/concept-connectors.html#how-to-create-a-connector["如何建立控制台代理"^]。



== 創建系統

如果您還沒有這樣做，您需要為來源和目標建立系統。

* https://docs.netapp.com/us-en/cloud-manager-fsx-ontap/start/task-getting-started-fsx.html["建立Amazon FSx for ONTAP系統"^]

* https://docs.netapp.com/us-en/cloud-manager-cloud-volumes-ontap/task-adding-systems.html["新增現有的Cloud Volumes ONTAP系統"^]
