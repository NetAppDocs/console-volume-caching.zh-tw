= 磁碟區快取常見問題解答
:hardbreaks:
:allow-uri-read: 
:icons: font
:imagesdir: ../media/


[role="lead"]
如果您只是想快速找到問題的答案，此常見問題解答可以為您提供協助。

*卷宗快取 URL 是什麼？ *在瀏覽器中輸入網址： https://console.netapp.com/["https://console.netapp.com/"^] 造訪BlueXP控制台。

使用卷宗快取需要許可證嗎？不需要NetApp許可證文件 (NLF)。

如何啟用卷宗快取？磁碟區快取無需任何啟用操作。磁碟區快取選項會自動顯示在NetApp Console左側導覽列中。
