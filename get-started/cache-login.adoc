= 存取 NetApp Volume Caching
:hardbreaks:
:allow-uri-read: 
:icons: font
:imagesdir: ../media/


[role="lead"]
您可以使用NetApp Console存取卷宗快取選項。

若要登入NetApp Console，您可以使用NetApp支援網站憑證。 https://docs.netapp.com/us-en/cloud-manager-setup-admin/task-logging-in.html["了解有關登入的更多信息"^] 。

.步驟
. 開啟 Web 瀏覽器並前往 https://console.netapp.com/["NetApp控制台"^]。
+
出現NetApp Console登入頁面。

. 登入控制台。
. 從控制台左側導覽中，選擇*移動性*>*卷快取*。
+
磁碟區快取儀錶板隨即出現。 image:landing-page.png["磁碟區快取登陸頁的圖片"]

+

NOTE: 如果未設定控制台代理，則會出現選項*新增控制台代理*。請參閱link:../get-started/cache-setup.html["設定卷緩存"]。
